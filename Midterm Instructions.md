## Problem 1

You will create an application that utilizes generative-AI architectures.  You are free to use any AI API, although I recommend picking one that is free.  You may focus on unimodal or multimodal models, and the purpose of your application is completely open.  Do note that the usefulness of your product will influence your overall grade.  I also know some of you may have your own work in this arena.  This needs to be completely distinct from anything else you have done.

You need to build a user interface for your application.  You may choose to run it offline using a framework such as TKinter or build a web-based application that you host locally. You are also welcome to host using a service, but this would add an extra layer of complexity, so it's not something I would expect or recommend. The user needs to be able to interact with your application, and this interaction will trigger some number of model calls.

A couple of hints: the most unpredictable part of this process will be registering with an API service and getting your application to communicate to this service.  I would recommend some light testing on this end first.  Additionally, some free APIs have usage limits, so note that you may only get, say, 20 API calls per 24 hours.  Plan accordingly.

It was mentioned earlier, but you are allowed to use an AI tool to help you generate your interface.  However, its generative use is restricted to your interface alone.

One final note: I understand that these requirements may seem vague or ambiguous.  That is partially the point.  The goal of this project is for you to start with an idea and create a prototype that is embedded with AI, regardless of the field or who your users may be.  I will subjectively judge on how effective I feel that it is, but it is your responsibility to figure out the exact capabilities of your application.
